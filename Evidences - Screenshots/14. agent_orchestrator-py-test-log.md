## Policy Summary: Return Policy for Premium Customers

Based on the retrieved policy documents, here is the comprehensive return policy information for **Premium tier customers**:

### **Returns Policy**

**Return Window:**
- **Premium customers** receive an **extended 60-day return window** (compared to 30 days for Standard tier customers)
- This window is calculated from the date of delivery

**Eligible Items for Return:**
- **Electronics:** Must be in original packaging with all accessories included
- **Clothing and Footwear:** Must be unworn, unwashed, with original tags attached
- **Appliances:** Must be unused and in original packaging
- **Books and Media:** Eligible for return only if defective

**Ineligible Items:**
- Perishable goods (food, flowers, plants)
- Personalized or custom-made items
- Digital downloads and software licenses
- Items marked as "Final Sale"
- Hazardous materials

**Return Process:**
1. Log in to account and navigate to Order History
2. Select the item to return and click "Start Return"
3. Choose reason for return from dropdown menu
4. Print the prepaid return shipping label
5. Pack the item securely and drop off at any authorized carrier location
6. Refunds are processed within **5-7 business days** of receiving the return

**Refund Methods:**
- Original payment method (credit/debit card): 5-7 business days
- Store credit: Immediate upon return approval
- Gift returns: Store credit only

**Special Circumstances:**
- **Damaged or Defective Items:** Contact customer support within 48 hours of delivery for free return and replacement at no additional cost
- **Exchanges:** Direct exchanges available for clothing and footwear; all other exchanges must be processed as return followed by new purchase
